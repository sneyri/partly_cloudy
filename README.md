# partly_cloudy
Сайт/обзор мультфильма "Переменная облачность"

Открыть: просто запусти `index.html` в браузере. Сервер не нужен.

**Как поменять цитату на главной:** в `index.html` найди блок с рамкой `ЦИТАТА НА ГЛАВНОЙ`
и замени текст внутри `<p class="quote__text">…</p>` (сама фраза) и `<cite class="quote__author">…</cite>` (подпись).
